# evolve

An ecosystem simulation in Rust, written from scratch to learn how each part of a game stack works. Plants grow, herbivores eat them, carnivores hunt herbivores, and animals pass traits to their offspring with small mutations.

## Credit

The idea comes from [Evolution.io](https://github.com/nasselk/Evolution.io) by Nassim EL KARATI (nasselk), a TypeScript ecosystem simulator with carnivores, herbivores and plants.
